雲端與第三方服務聲明

Cloud & Third-Party Services Disclaimer

最後更新日期：2026 年 10 月

Orbit Tower 可能整合以下第三方平台與服務。第三方平台若變更政策、費率或功能，不屬於 Orbit Tower 控制範圍。

一、整合平台

Orbit Tower 可能整合之第三方平台包括但不限於：

  • Vercel — 網站部署與全球 CDN 加速
  • Cloudflare — DNS 管理、安全防護與效能優化
  • Microsoft — Azure 雲端服務、Office 365 整合
  • Google — Google Cloud、Google Workspace、Analytics
  • OpenAI — GPT 系列 AI 模型服務
  • Anthropic — Claude 系列 AI 模型服務
  • Meta — Llama 系列開源模型、社群整合
  • 其他第三方平台與 API 服務

二、服務依賴聲明

Orbit Tower 之部分功能依賴第三方平台之正常運作：

  • 網站部署與 CDN 依賴 Vercel 或 Cloudflare 之服務。
  • AI 功能依賴 OpenAI、Anthropic 等 AI 模型服務。
  • 分析功能依賴 Google Analytics 等數據平台。
  • 郵件服務依賴第三方郵件平台。

三、政策變更風險

第三方平台可能單方面變更以下事項：

  • 服務費率：價格調整可能影響維運成本。
  • 使用條款：政策更新可能影響功能可用性。
  • API 限制：配額或速率限制變更可能影響效能。
  • 功能調整：功能下架或改版可能影響現有流程。
  • 區域可用性：服務區域變更可能影響存取。

四、Orbit Tower 之應對

面對第三方平台變更，Orbit Tower 將：

  • 持續監控所依賴平台之政策與服務狀態。
  • 建立替代方案以確保服務連續性。
  • 於合理期限內通知客戶重大變更。
  • 協助客戶進行必要之調整與遷移。

五、責任歸屬

  • 第三方平台之服務中斷、資料遺失或安全事件，由該平台負責。
  • Orbit Tower 將盡力協助排除問題，但不承擔第三方平台之責任。
  • 建議客戶定期備份重要資料。
